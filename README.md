# Jafar-Services-Management
A lightweight tool to efficiently and rapidly manage and repair Windows services.

I am Jafar from Iraq, 14 years old. I am passionate about operating systems, specifically Windows internals and architecture. My main focus is on system maintenance and troubleshooting, and I develop specialized maintenance tools using C# to deliver fast and efficient software solutions. Developing this project took 93 days of continuous work and intensive research.

The Jafar Services Management (JSM) project is a tool designed to manage Windows services smoothly while offering advanced maintenance solutions. Built on .NET 10 and compiled using ReadyToRun (R2R) technology, it ensures high performance and fast execution. 

The tool features two primary capabilities:
* **Orphan Services Detector:** Cleans up leftover service remnants in the system.
* **Automatic Services Analyzer:** Examines services that start automatically (invoked by the Service Control Manager in user mode before the lock screen appears).
